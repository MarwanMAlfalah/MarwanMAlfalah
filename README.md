## Selected Research Systems

### [Vendor-Agnostic Industrial Orchestrator](https://github.com/MarwanMAlfalah/vendor-agnostic-industrial-orchestrator)

Governance-aware AI orchestration research prototype with capability matching, approval boundaries, deterministic evaluation, traceability, and reproducibility artifacts.

*Python · FastAPI · LangGraph · Docker*

### [Deep Synaptica](https://github.com/MarwanMAlfalah/deep-synaptica)

Agent observability and evaluation infrastructure exposing run-level traces, tool behavior, latency, and outputs through a FastAPI backend and Next.js dashboard.

*Python · FastAPI · Next.js · TypeScript · LLM APIs*

### [Clinical Documentation Intelligent Control System](https://github.com/MarwanMAlfalah/clinical-doc-ics-demo)

Research prototype integrating ASR, LLM-generated structured documentation, supervisory control, human review, and explicit state tracking.

*Python · Whisper · LLM APIs · Streamlit*

### [Hallucination Detection from Hidden States](https://github.com/MarwanMAlfalah/smiles-2026-hallucination-detection)

Reproducible hidden-state probing study using Qwen2.5-0.5B representations for hallucination detection and internal model evaluation.

*Python · Transformers · scikit-learn · Evaluation*

### [TeraFinder](https://github.com/MarwanMAlfalah/OS_BOOTCAMP-LLM)

Team-built multi-agent, multi-source information retrieval system using LangGraph and evidence-oriented search workflows; I contributed during the ITMO × Sber AI Open Source BootCamp.

*Python · LangGraph · LLM APIs*
